# MAPPER

MAPPER (Mapping Associated Phenotype Programs to Expression-Resolved Niches) is a learning-transfer framework that trains a phenotype-specific teacher on clinically annotated bulk transcriptomic cohorts and applies the frozen model to single-cell or spatial transcriptomic data. By jointly scoring each cell or spot and its physically defined neighbourhood against outcome-informed reference levels derived from the bulk cohort, MAPPER produces calibrated positive, background and negative maps of phenotype-associated tissue niches. These maps support downstream survival validation and spatial analyses of niche composition, co-localization and cellular organization across two- and three-dimensional tissues.
